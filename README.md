# Institutional Effectiveness & Accreditation at Berea College

Plain HTML site, published with GitHub Pages at `bereacollege-ie.github.io/ie`.

## What's where

| Path | What it is |
|---|---|
| `index.html` | Homepage |
| `assessment/`, `accreditation/`, `ai/`, `data/` | One folder per section, each with an `index.html` |
| `search/` | Search results page |
| `files/` | Downloadable documents, one subfolder per section |
| `assets/css/site.css` | All styling (2026 Berea brand colors and fonts) |
| `assets/js/search.js` | Site search |
| `assets/img/` | Approved logo artwork from the Brand Toolkit |
| `partials/` | The shared header and footer. Edit these, not the copies inside pages |
| `tools/build.py` | The build step (see below) |
| `tools/site_config.json` | Contact line and Academic Affairs homepage link used in every footer |
| `search-index.json` | Generated by the build; don't edit by hand |

## Making a change

1. Edit the page, the partial, or the stylesheet.
2. From this folder, run `python3 tools/build.py`. It:
   - copies the header and footer into every page,
   - marks the current section in the menu,
   - fills each page's "Page last reviewed" date from its `<meta name="last-reviewed">` tag,
   - rebuilds the search index,
   - flags any em dash or broken link.
3. Commit and push. GitHub Pages republishes in a minute or two.

## Adding a downloadable file

1. Copy it into the right `files/<section>/` subfolder with a lowercase, hyphenated name.
2. Add a row to the page inside its `<ul class="resources">` list, copying an existing `<li data-resource="...">` row.
3. Run the build. The file shows up in search automatically.

The files here are copies. Updating an original in the Assessment folder doesn't change the site until the new version is copied over.

## Passphrase-protected dashboards (later)

Encrypt before anything reaches the repo. Git history is permanent, so an unencrypted file committed even once stays recoverable from the public repo.
